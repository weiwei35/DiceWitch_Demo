# 地图新建手册

这份文档用于从 0 新建一个章节地图。面向美术和策划，重点说明在 Unity 里要创建什么、拖到哪里、怎么检查。

## 一句话理解地图结构

地图由这几层组成：

- **整张地图配置**：决定本局地图由哪些章节组成。
- **章节 Region**：游戏的一个完整段落，通常以 Boss 房间结尾。
- **房间 Room**：玩家走到某段节点后触发的内容，比如战斗、事件、起点。
- **节点 Node**：地图上玩家棋子可以停留的位置，负责提供格子效果，比如回血、给资源、锻造、下场战斗加护甲。

简单理解：

`整张地图 -> 章节 -> 房间 -> 节点`

## 第 1 步：准备地图表现配置

地图上所有房间图标、节点效果图标、tooltip 文案、节点颜色，都放在同一个表现配置里。

1. 在 Project 窗口右键。
2. 选择 `Create -> Map -> Presentation Catalog`。
3. 命名，例如 `MapPresentationCatalog_Default`。
4. 选中这个文件，在 Inspector 右上角菜单里执行：
   `Fill Missing Default Entries`
5. 给里面的内容补图标：
   - `Room Icons`：配置起点、普通战斗、精英、Boss、事件等房间图标；需要边框的房间类型同时配置 `Frame Sprite`。
   - `Node Effects`：配置回血、资源、护甲、必中骰子、锻造等节点效果图标。
   - `Forge Icon`：配置锻造图标。

注意：`Fill Missing Default Entries` 只会补缺失项，不会清空已经配置好的图标和文案。

## 第 2 步：创建房间数据

每个房间都需要一个对应的房间数据文件。

### 起点房间

1. 右键 Project 窗口。
2. 选择 `Create -> Map -> Room -> Start Room`。
3. 命名，例如 `Room_Start`。
4. 填写：
   - `Room Name`：起点
   - `Description`：可以写给 tooltip 用的简短描述

起点房间不会触发战斗或事件，只用于放置玩家棋子的起始位置。

### 战斗房间

1. 右键 Project 窗口。
2. 选择 `Create -> Map -> Battle Room`。
3. 命名，例如 `Room_Battle_01`。
4. 填写：
   - `Room Name`：房间名
   - `Enemy Wave`：本房间敌人配置
   - `Reward Ability Draft`：是否战斗后出现法术三选一奖励

### 事件房间

1. 右键 Project 窗口。
2. 选择 `Create -> Map -> Room -> Event Room`。
3. 命名，例如 `Room_Event_01`。
4. 填写事件相关配置。

## 第 3 步：制作一个房间

房间是地图配置的主要单位。建议每个房间单独整理成一个对象或 prefab。

一个房间需要挂 `MapRoomLayout`，并配置：

- `Room Data`：拖入刚才创建的房间数据，例如 `Room_Battle_01`。
- `Room Nodes`：按玩家前进顺序，把这个房间里的节点拖进去。
- `Next Rooms`：如果这个房间结束后会分岔，就拖入后续可选房间；没有分岔可以留空。

## 第 4 步：配置房间里的节点

每个节点需要挂 `MapNodeAnchor`。

节点只需要配置自己的格子效果：

- `Node Type`：节点效果类型。
- `Effect Value`：效果数值。
- `Forge Bonus Type`：只有锻造节点需要配置。

常见节点示例：

- 普通空节点：
  - `Node Type = 空`
  - `Effect Value = 0`

- 回血节点：
  - `Node Type = 加减Hp`
  - `Effect Value = 3`

- 扣血节点：
  - `Node Type = 加减Hp`
  - `Effect Value = -3`

- 获得资源：
  - `Node Type = 加减资源`
  - `Effect Value = 20`

- 下场战斗必中骰子：
  - `Node Type = 骰子点数必中`
  - `Effect Value = 6`

- 锻造节点：
  - `Node Type = 锻造`
  - `Effect Value = 3`
  - `Forge Bonus Type = 加减Hp`

锻造节点一定要配置 `Forge Bonus Type`。例如 “锻造 + 回 3 血”，就设置为：

- `Node Type = 锻造`
- `Effect Value = 3`
- `Forge Bonus Type = 加减Hp`

节点的主图标不用手动选择贴图，它会自动根据房间类型显示。例如战斗房显示战斗图标，起点房显示起点图标。

节点预制体需要显式配置以下 UI 引用：

- `Base Icon Image`：房间主图标。
- `Frame Image`：房间边框对象。
- `Effect Icon Image`：节点效果图标。
- `Value Text`：节点效果数值。
- `Passed Background Image`：玩家抵达节点后显示的独立背景图，保持居中并固定为 `180×180`；运行时不会按 Sprite 原尺寸重设大小。

每个非起点节点还要填写 `Passed Background Sprite Name`，内容是图片的 Sprite 名称，不写 `.png`，例如 `A1`、`I6`。起点没有对应背景图时可以留空。

边框的位置、大小、层级和 Image 样式由节点预制体控制。运行时只读取 `Presentation Catalog -> Room Icons -> Frame Sprite`：配置了贴图就显示边框，没有配置就隐藏。系统不会再自动创建或查找 `RoomFrame`。

## 第 5 步：组装章节 Region

一个章节需要挂 `MapRegionLayout`。

在 `MapRegionLayout` 里配置：

- `Base Grid Root`：可选的独立基础格纹根节点；若底图直接配置在 Region 根对象的 `Image` 上，这里可留空。
- `Passed Grid Reveal Layer`：真正抵达过的节点使用的格纹覆盖层；该对象需要挂 `MapGridRevealLayer`，并绑定遮罩 Shader 与完整覆盖图的所有 `Image`。失效分支不会揭示格纹。
- `Passed Route Reveal Layer`：手绘路线根节点上控制“路线（已经过）”的 `MapGridRevealLayer`。
- `Ordered Rooms`：按大致前进顺序，把这一章里的房间拖进去。

路线连接使用两张完整手绘贴图：把“路线（未经过）”放在底层常驻显示，把“路线（已经过）”放在上层并交给 `Passed Route Reveal Layer`。运行时不会自动生成点状连接线。路线 Image 应关闭 `Raycast Target`，避免挡住地图拖拽和节点交互。

运行时，已走格纹仍以真正抵达过的节点为圆心揭示，并显示该节点自己的背景图；未选择而失效的分支不会揭示格纹或节点背景。已经过路线使用更简单的规则：以棋子当前 X 坐标为竖向分界，左侧路线全部显示为已经过，右侧保持未经过。格纹圆形半径、格纹羽化和路线分界羽化都在场景中的 `MapViewController` 上配置。

章节通常建议这样组织：

1. 起点房间
2. 普通战斗或事件房间
3. 若干分岔房间
4. Boss 房间

章节最后一个房间建议是 Boss 房间。

## 第 6 步：配置分岔

分岔配置在房间上，不配置在节点上。

如果某个房间结束后有两个可选房间：

1. 选中这个房间的 `MapRoomLayout`。
2. 在 `Next Rooms` 里加入两个后续房间。

如果 `Next Rooms` 为空，系统会默认连接到 `Ordered Rooms` 中的下一个房间。

## 第 7 步：配置整张地图

整张地图使用 `BoardMapConfigSO`。

1. 在 Project 窗口右键。
2. 选择 `Create -> Map -> Board Map Config`。
3. 命名，例如 `BoardMapConfig_Chapter01`。
4. 配置：
   - `Presentation Catalog`：拖入地图表现配置。
   - `Node Passed Background Folder`：拖入这张地图所有节点已抵达背景图所在的文件夹。
   - `Regions`：按顺序拖入章节 prefab。

配置或更新文件夹后，在 `BoardMapConfigSO` 的 Inspector 右上角菜单执行 `Refresh Node Passed Backgrounds From Folder`。系统会把文件夹中的 Sprite 名称建立成运行时索引，不需要把图片移动到 `Resources`。

如果只有一个章节，就只配置一个 Region。

## 第 8 步：放置玩家起点

玩家棋子的起点应该放在起点房间里。

推荐做法：

1. 创建 `Start Room` 数据。
2. 做一个起点房间对象，挂 `MapRoomLayout`。
3. 把 `Room Data` 设置为 `Start Room`。
4. 在这个房间里放一个起点节点。
5. 起点节点设置为：
   - `Node Type = 空`
   - `Effect Value = 0`

不要用 `Battle Room` 假装起点。战斗房间运行时会自动变成战斗类型，图标也会变成战斗图标。

## 第 9 步：检查地图配置

配置完成后，可以运行地图检查工具。

1. 在 Project 窗口选中你的 `BoardMapConfigSO`。
2. 点击 Unity 顶部菜单：
   `DiceWitch -> Map -> Validate Selected Map Config`
3. 查看 Console 输出。

检查工具会提示：

- 是否缺少表现配置。
- 章节是否缺少 prefab。
- 房间是否缺少 `Room Data`。
- 房间是否没有节点。
- 锻造节点是否忘记配置额外效果。
- 节点预制体是否缺少边框等 UI 引用。
- 非起点节点是否缺少背景图片名，或者名字无法在背景文件夹中找到。
- 是否缺少已经过路线遮罩层。
- 章节最后一个房间是否不是 Boss。
- 表现配置里是否缺少 icon。

## 常见问题

### 为什么我把房间类型改成起点，运行后又变成战斗？

因为房间类型不是手动改的，而是由房间数据文件本身决定。

- 起点必须使用 `StartRoomSO`。
- 战斗必须使用 `BattleRoomSO`。
- 事件必须使用 `EventRoomSO`。

不要在 Inspector 里手动改房间类型。

### 为什么节点主图标不对？

节点主图标由房间类型决定。

请检查：

1. 房间的 `Room Data` 是否正确。
2. `Presentation Catalog` 中对应房间类型是否配置了 icon。

### 为什么锻造节点没有显示额外效果？

请检查锻造节点：

- `Node Type` 是否为 `锻造`
- `Forge Bonus Type` 是否已配置
- `Effect Value` 是否填写
- `Presentation Catalog` 中是否配置了对应效果 icon

## 推荐命名

为了方便查找，建议这样命名：

- 地图表现配置：`MapPresentationCatalog_Default`
- 整张地图配置：`BoardMapConfig_Chapter01`
- 起点房间：`Room_Start`
- 普通战斗房：`Room_Battle_01`
- 事件房：`Room_Event_01`
- Boss 房：`Room_Boss_01`
- 章节 prefab：`Region_Chapter01`

## 最终配置清单

完成一章地图前，确认这些都已经配置：

- 已创建 `MapPresentationCatalogSO`
- 已给 catalog 补房间 icon 和节点效果 icon
- 已创建起点房间数据
- 已创建战斗/事件/Boss 房间数据
- 每个房间都挂了 `MapRoomLayout`
- 每个房间都配置了 `Room Data`
- 每个房间都配置了 `Room Nodes`
- 分岔房间配置了 `Next Rooms`
- 每个节点都配置了 `Node Type`
- 每个非起点节点都配置了 `Passed Background Sprite Name`
- 锻造节点配置了 `Forge Bonus Type`
- 章节 `MapRegionLayout` 配置了 `Ordered Rooms`
- 整张地图 `BoardMapConfigSO` 配置了 `Presentation Catalog`
- 整张地图配置了节点背景文件夹并刷新了 Sprite 索引
- 整张地图 `BoardMapConfigSO` 配置了 `Regions`
- 已运行地图检查工具
